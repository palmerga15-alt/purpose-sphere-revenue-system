## Security Model

The public repository contains dashboard code and sample data only.

Sensitive financial information, credentials, private business records, and proprietary materials should not be committed to this repository.

The architecture is designed to support:

- Privacy-first display controls
- Local/manual data handling
- Validation before rendering
- Future authenticated backend connections
- Private storage outside the public repository
